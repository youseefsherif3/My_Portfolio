## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/youseefsherif3/My_Portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
